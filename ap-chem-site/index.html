核心：从「克」走到「个数」的桥梁

化学家用摩尔把宏观的质量和微观的粒子数连起来。三个量之间的换算只有两条路，都要经过摩尔这个中转站。

n = m / M物质的量(mol) = 质量(g) ÷ 摩尔质量(g/mol)
N = n × NA粒子数 = 物质的量 × 6.022×10²³
ρ = m / V密度 = 质量 ÷ 体积（常用于溶液的浓度换算）
换算地图：质量 —(÷ M)→ 摩尔 —(× NA)→ 粒子数；反向就是 × M 和 ÷ NA。
摩尔质量在数值上等于元素的平均原子质量：1 mol C = 12.0 g，1 mol Mg = 24.3 g，1 mol Cu = 63.5 g。
例题（PPT Unit 1.1 第 3 题）：88 g 金里含有多少个原子？
① n = 88 ÷ 197 = 0.447 mol（Au 摩尔质量 197 g/mol）
② N = 0.447 × 6.022×10²³ ≈ 2.7 × 10²³ 个原子

例题（PPT 第 5 题）：Na₂Cr₂O₇ 的摩尔质量是多少？
2×22.99（Na）+ 2×52.00（Cr）+ 7×16.00（O）= 262 g/mol

怎么读一张质谱图

质谱仪把原子电离后按质量分开：横轴是质荷比，纵轴是相对丰度。它是「同种元素存在不同质量原子」最直接的证据。

峰的位置= 该同位素的质量（质荷比 m/z）
峰的高度= 该同位素的相对丰度（%）
平均原子质量 = Σ(同位素质量 × 丰度)每个同位素都要按自己的丰度加权
⚠ 最容易混的地方：质谱的横轴是质量，PES 的横轴是电子的结合能。两个图都叫「谱」，但测的东西完全不同。
例题：铜有两种天然同位素 ⁶³Cu（69.15%）和 ⁶⁵Cu（30.85%），平均原子质量是多少？
63 × 0.6915 + 65 × 0.3085 = 43.56 + 20.05 = 63.61 ≈ 63.5

快速自检：平均值一定落在两个同位素质量之间，而且更靠近丰度大的那一个。63.5 明显更接近 63，说明 ⁶³Cu 更丰富。如果你算出 64.5，就是把丰度用反了。

¹²C 基准：¹²C 的质量被定义为恰好 12 u，其他原子的质量都是相对它给出的。天然碳约含 98.89% 的 ¹²C 与 1.11% 的 ¹³C，所以碳的原子量是 12.01 而不是整数 12。

从质量百分比推到化学式：四步走

这是 Unit 1 计算题的绝对主角。把下面四步练成肌肉记忆，绝大多数题都能顺下来。

  1. 假设取 100 g 样品 —— 这样百分比就直接变成克数，不用再算一遍。
  2. 每种元素除以它的摩尔质量，把「克」换成「摩尔」。
  3. 全部除以最小的那个摩尔数，得到最简整数比 → 这就是实验式（最简式）。
  4. 如果题目给了摩尔质量：倍数 = 摩尔质量 ÷ 实验式式量，实验式乘上倍数 → 分子式。
例题（PPT Unit 1.3 Example 1）：含 47.08% C、6.59% H、46.33% Cl，摩尔质量 153 g/mol
① 取 100 g → C 47.08 g、H 6.59 g、Cl 46.33 g
② 除以摩尔质量：C 47.08/12.01 = 3.92；H 6.59/1.008 = 6.54；Cl 46.33/35.45 = 1.31
③ 全部除以最小值 1.31 → 3 : 5 : 1 → 实验式 C₃H₅Cl（式量 76.5）
④ 153 ÷ 76.5 = 2 → 分子式 C₆H₁₀Cl₂
另一类高频问法（用元素含量反推纯度）：纯 CaCO₃ 中 Ca 占 40%，而样品只测出 30% 的 Ca，说明它不是纯的 →
CaCO₃ 含量 = 30% ÷ 40% = 75%。同理可判断「含 75% Cl 的食盐其实是掺了 LiCl（LiCl 的 Cl 含量更高）」。

限量反应物：谁先耗尽谁说了算

只要反应物不止一种，就必须先判断谁是限量试剂（limiting reactant），否则算出来的产量一定是错的。

  1. 把所有反应物都换算成摩尔（n = m/M）。
  2. 各自除以方程式里的系数，得到「相对需求量」。
  3. 商最小的那个就是限量反应物，产物的量完全由它决定，其余都是过量的。
  4. 用限量试剂的摩尔数 × 系数比算出产物摩尔数，再乘摩尔质量换成克。
例题（PPT Unit 1.4 Example 1）：6 g H₂ 与 160 g O₂ 反应，2H₂ + O₂ → 2H₂O，最多生成多少水？
① n(H₂) = 6/2 = 3 mol；n(O₂) = 160/32 = 5 mol
② 除以系数：H₂ → 3 ÷ 2 = 1.5；O₂ → 5 ÷ 1 = 5
③ 1.5 < 5 → H₂ 是限量反应物，O₂ 过量
④ 生成 H₂O = 3 mol × 18 g/mol = 54 g
常见错误：直接拿 5 mol O₂ 去算得到 180 g —— 这是把过量的那个当成限量了。
产率 = 实际产量 ÷ 理论产量 × 100%理论产量永远由限量试剂算出，与过量试剂无关
混合物分析的套路：让混合物里只有一种成分参与反应（或分别反应），用产物的量反推该成分的量，再除以样品总质量 → 质量分数。

峰的位置由两个因素决定：

周期趋势热力图

同一张周期表，切换不同性质（半径 / 电离能 / 电负性），颜色呈现规律性的递变。

详细讲解　周期趋势可由「有效核电荷 + 电子层」两条主线推出。
  • 原子半径：同周期从左到右减小；同族从上到下增大。
  • 第一电离能：同周期总体增大（越难失电子）；同族减小。
  • 电负性：同周期增大、同族减小，右上角（F、O）最强。
把同一张周期表切换成不同性质来「上色」，就能一眼看出规律性递变——这正是周期律的精髓。

库仑定律与有效核电荷

核电荷越大，对外层电子的库仑吸引越强——这正是原子半径与电离能周期趋势的根源。

详细讲解　库仑定律 F ∝ q₁q₂ / r² 是理解原子与周期趋势的底层逻辑。
  • 核电荷（质子数）越大，对外层电子的有效核电荷越大，吸引越强。
  • 电子被拉得越近 → 半径越小；移走电子（电离）需要的能量越大。
由此可得周期趋势：同周期从左到右半径减小、电离能/电负性增大；同主族从上到下半径增大、电离能减小。记住「电荷越大、距离越近 → 作用越强」这一条主线，很多趋势都能推出来。

价电子决定离子电荷，离子电荷决定化学式

主族元素的典型离子电荷，由它在周期表中的位置直接决定 —— 不用背，看族数就行。

1 族（Na、K）失去 1 个电子 → 1+　　2 族（Mg、Ca）→ 2+　　13 族（Al）→ 3+
15 族（N、P）得到 3 个电子 → 3−　　16 族（O、S）→ 2−　　17 族（F、Cl）→ 1−

规律：金属失电子变阳离子、非金属得电子变阴离子，目标都是达到最近稀有气体的电子构型（八隅体）。
写化学式的交叉法：把两种离子电荷的绝对值交叉写到对方右下角，再约到最简。
Na⁺ + O²⁻ → Na₂O　|　Mg²⁺ + N³⁻ → Mg₃N₂　|　Al³⁺ + O²⁻ → Al₂O₃　|　Ca²⁺ + F⁻ → CaF₂
例题（PPT Unit 1.8）：写出下列组合的化学式
Na + O → Na₂O　　Mg + N → Mg₃N₂　　K + P → K₃P
Al + O → Al₂O₃　　Ca + F → CaF₂　　Be + O → BeO
为什么同族能「类比」？Mg 和 F 按 1 : 2 结合成 MgF₂，同族的 Ba 和 F 也是 1 : 2（BaF₂）—— 因为同族元素价电子数相同，所以形成化合物的比例相同、化学性质相似。这就是判断「与 Mg 化合比例相同的元素」这类题的依据。

杂化轨道形成

一个 s 轨道与三个 p 轨道重新组合，形成四个能量相同、指向四面体顶点的 sp³ 杂化轨道。

详细讲解　杂化轨道理论解释分子的几何构型。
  • 中心原子的 1 个 s 轨道与 3 个 p 轨道重新组合，形成 4 个能量完全等价的 sp³ 杂化轨道。
  • 它们尽量远离，指向正四面体的四个顶点，夹角 109.5°。
由此 CH₄ 是正四面体、H₂O/NH₃ 是在四面体基础上因孤对而「压扁」。规律：电子域数 = 4 → sp³，3 → sp²（120°），2 → sp（180°）。

路易斯结构分步绘制

按「价电子 → 成键 → 补孤对」的顺序逐步画出一个分子的完整路易斯结构（以 H₂O 为例）。

详细讲解　路易斯结构用「点」表示价电子，画法有固定三步：
  • 数总价电子数（含电荷修正）；
  • 把中心原子与外围原子用共用电子对（单/双/三键）连接；
  • 剩余电子作为孤对补齐，使各原子尽量满足八隅体。
孤对会「占据空间」并压缩键角（如 H₂O 的 104.5° < 109.5°）。它也是判断分子极性、几何构型与反应活性（孤对可作为电子对给体）的关键。下方可切换查看多个经典分子的路易斯结构。

成键过程动画

两个原子从远处靠近，势能沿曲线下降，直到最低点——那就是键长与键能。

详细讲解　把两个原子从无穷远处慢慢靠近：吸引（核与对方电子）使势能下降，排斥（核与核、电子与电子）使势能上升。
  • 势能最低点对应的核间距就是键长——此时体系最稳定，原子「愿意」保持这个距离。
  • 最低点的深度就是键能：要拆开这个键必须输入这么多能量。深度越深，键越强、越难断裂。
  • 再靠近时排斥急剧上升，势能陡增——这解释了为什么原子不会无限靠近、分子有固定大小。
考试要点：读懂势能曲线、由最低点读键长与键能，是 AP 判断键强/键长、比较不同分子稳定性的基础。

超过八隅体结构（扩展八隅体）八隅体例外

八隅体规则对第二周期（C、N、O、F）严格成立；但第三周期及以后的中心原子（P、S 等）有空的 3d 轨道，可容纳超过 8 个电子。

  • SO₂（二氧化硫）：S 有 6 个价电子，形成 2 个 S=O 双键 + 1 对孤对 → S 周围 10 e⁻。3 个电子域 → 角形，键角约 119°。按单双键画有 2 个等价共振式，S–O 键级 1.5。
  • SO₃（三氧化硫）：S 有 6 个价电子，3 个 S=O 双键 → S 周围 12 e⁻，无孤对。平面三角形 120°。按单双键画有 3 个等价共振式，S–O 键级 4/3。
  • PCl₅（五氯化磷）：P 有 5 个价电子，5 个 P–Cl 单键 → P 周围 10 e⁻，无孤对。三角双锥，键角 90° 和 120°，无共振。
  • SF₆（六氟化硫）：S 有 6 个价电子，6 个 S–F 单键 → S 周围 12 e⁻，无孤对。正八面体，键角 90°，无共振。
对照八隅体：常规八隅体（H₂O、CH₄、CO₂，中心原子 8 e⁻）｜缺电子（BF₃ 的 B 仅 6 e⁻）｜超八隅体（PCl₅ = 10 e⁻、SF₆ = 12 e⁻）。超八隅体只出现在第三周期及以后、半径较大的中心原子上。

伦敦色散力

电子云的瞬时偏移产生瞬时偶极，又诱导邻近分子产生偶极，两者相互吸引。

详细讲解　伦敦色散力是所有分子都具有的分子间作用力。
  • 电子时刻在运动，某一瞬间电子偏向一侧，就产生瞬时偶极（δ⁺/δ⁻）。
  • 这个瞬时偶极又诱导邻近分子产生同向偶极，两者相互吸引。
规律：分子越大（电子越多、越易被极化），色散力越强 → 沸点越高。这就是同族卤素/惰性气体从上到下沸点升高的原因（它们都没有偶极或氢键，只有色散力）。

固 → 液 → 气：相变时分子在做什么

相变改变的是分子之间的作用力，而不是分子内部的化学键——分子始终保持完整。

固体：只在原位振动
液体：紧挨着滑动、碰撞
气体：自由飞行、间隔很大
蒸发与蒸气压：液体的蒸气压是汽液平衡时的蒸气压强。IMF 越强 → 分子越难逃逸 → 蒸气压越低、沸点越高。
排序示例：25 °C 下蒸气压 Cl₂ > Br₂ > I₂（分子越大、色散力越强，越难逃逸）。

气体粒子的运动（分子动理论）

气体的压强来自粒子撞击器壁。看左上角的粒子在盒子里随机飞行、碰壁反弹——温度越高，跑得越快。

粒子随机运动 → 碰壁产生压强
温度升高，分布右移、峰变低
KMT 四条假设：① 粒子体积可忽略；② 粒子不停随机运动，碰壁即压强；③ 粒子之间无吸引/排斥；④ 平均动能正比于开尔文温度（KE = ½mv²）。
理想气体定律：PV = nRT（R = 0.08206 L·atm/mol·K）。
分压（道尔顿）：P总 = PA + PB + …，且 PA = P总 × XA，XA = nA/n总。
例题（PPT）：23 °C、25.0 L、3.18 atm 的轮胎里有多少摩尔空气？
n = PV/RT = (3.18 × 25.0) ÷ (0.08206 × 296) = 79.5 ÷ 24.29 ≈ 3.27 mol。

真实气体为什么会偏离理想行为

两个原因：分子之间的吸引，以及分子本身占的体积。

① 分子间吸引：在低温、接近液化时最明显，使压强低于理想值；
② 分子本身体积：在极高压下最明显，使压强高于理想值。

什么时候最接近理想气体？ 高温 + 低压——此时动能远大于分子间势能、粒子间距远大于粒子尺寸。

“相似相溶”与分离方法

溶解度规律：IMF 类型相似的物质更容易互溶（like dissolves like）。

三种方程式 · 旁观离子是怎么被删掉的

同一个反应可以有三种写法：分子方程式、完全离子方程式、净离子方程式。净离子方程式只保留真正发生变化的粒子。

Ag⁺ NO₃⁻ + Na⁺ Cl⁻ → Na⁺ NO₃⁻ + AgCl(s)
Na⁺ 与 NO₃⁻（灰色）两边都原样存在 → 它们是旁观离子，从净离子方程式中删去
① 分子方程式：AgNO₃(aq) + NaCl(aq) → AgCl(s) + NaNO₃(aq)
② 完全离子方程式：Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl(s) + Na⁺ + NO₃⁻
③ 净离子方程式：Ag⁺(aq) + Cl⁻(aq) → AgCl(s)
为什么必须配平：化学变化只是原子的重新组合，所以方程式中每种元素的原子数在反应前后必须相等 —— 这就是质量守恒。

怎么选写哪种形式

• 想看清实际参加反应的粒子 → 写净离子方程式；
• 想看清每种物质的完整形态（谁沉淀、谁放气） → 写分子方程式；
• 溶液中的反应，题目常要求「先写完全离子、再约掉旁观离子得到净离子」。

易错点：只有强电解质且溶于水的物质才拆成离子。弱酸（CH₃COOH）、弱碱、沉淀、气体、水都不拆。
例题（PPT）：Ag⁺ + Cl⁻ → AgCl(s)，其中 Na⁺ 和 NO₃⁻ 是旁观离子。

物理变化 vs 化学变化 · 分子层面发生了什么

区别不在于「看起来变没变」，而在于分子本身有没有被拆散重组。

物理变化：分子原样，只是分散开
化学变化：旧分子断裂 → 重组成新分子
物理变化：物质性质改变但组成不变。常见的是相变（固↔液↔气）与混合物的生成/分离。
化学变化：物质被转化为组成不同的新物质。

化学变化的四条证据：① 放出热或光；② 生成气体；③ 生成沉淀；④ 颜色改变。

沉淀反应过程

溶液中的离子自由移动，相遇后结合成难溶固体，逐渐沉降到容器底部。

详细讲解　沉淀反应是两种离子结合成难溶固体的过程。
  • Ag⁺ 与 Cl⁻ 在溶液中相遇，静电吸引使它们结合成难溶的 AgCl。
  • 固体不断聚集、长大，最终因密度较大而沉降到底部形成沉淀。
要点：是否生成沉淀由溶解度（Ksp）决定；净离子方程式中 Ag⁺ + Cl⁻ → AgCl(s)，旁观离子不参与。这也是定量分析（重量法、滴定）的基础。

滴定 · 从滴落到变色

滴定用已知浓度的滴定剂（titrant）去定量消耗待测物（analyte）。当待测物被恰好完全消耗时，到达等当点。

滴定剂逐滴落下 → 等当点附近指示剂突然变色（终点）
等当点（equivalence point）：待测物被滴定剂恰好完全反应的那一刻（理论点）。
终点（endpoint）：指示剂实际变色被观察到的那一刻（实验点）。
理想情况下两者重合 —— 这是选择指示剂的依据。
例题（PPT）：10.00 mL 的 HCl 用 0.6362 M NaOH 滴定，到达等当点用去 15.28 mL，求 HCl 的浓度。
n(NaOH) = 0.01528 × 0.6362 = 9.722 × 10⁻³ mol；HCl 与 NaOH 是 1 : 1；
M(HCl) = 9.722 × 10⁻³ ÷ 0.01000 = 0.9722 mol/L。

反应类型与溶解性规则

沉淀反应：两种溶液混合后生成难溶的离子化合物。例如 K₂CrO₄(aq) + Ba(NO₃)₂(aq) → BaCrO₄(s) + 2KNO₃(aq)。
酸碱反应：质子（H⁺）在两物种之间转移。
氧化还原反应：电子在两物种之间转移（详见下一节）。
燃烧反应：氧化还原的一类 —— 与 O₂ 反应。烃完全燃烧生成 CO₂ + H₂O；不完全燃烧还会生成 CO 与 C。
必背溶解性规则：所有 Na⁺、K⁺、NH₄⁺、NO₃⁻ 的盐都可溶 —— 这四类离子永远不会生成沉淀。

电子转移 · OIL RIG 动画

氧化还原反应的实质是电子从一个物种转移到另一个物种。失电子的被氧化、得电子的被还原 —— 两者永远同时发生。

Zn0被氧化
Cu²⁺+2被还原
Zn 失 2e⁻ → 氧化数 0 → +2（OIL）；Cu²⁺ 得 2e⁻ → 氧化数 +2 → 0（RIG）
口诀 OIL RIG：Oxidation Is Loss（氧化是失电子），Reduction Is Gain（还原是得电子）。
记忆技巧：氧化数升高 = 被氧化 = 还原剂；氧化数降低 = 被还原 = 氧化剂。

氧化数七条规则

① 单质中元素的氧化数 = 0
② 单原子离子的氧化数 = 该离子的电荷
③ 氧在共价化合物中 = −2（过氧化物中 = −1）
④ 氢在共价化合物中 = +1
⑤ 氟在化合物中 = −1（永远）
⑥ 化合物中各氧化数之和 = 0
⑦ 多原子离子中各氧化数之和 = 离子的电荷
例题（PPT）：求 K₂Cr₂O₇ 中 Cr 的氧化数。
设 Cr 为 x：2(+1) + 2x + 7(−2) = 0 → 2 + 2x − 14 = 0 → x = +6。
（同理 CO₃²⁻ 中 C 为 +4；MnO₂ 中 Mn 为 +4；PCl₅ 中 P 为 +5；H₂O₂ 中 O 为 −1。）

酸碱反应与半反应法

布朗斯特–劳里定义：酸 = 质子（H⁺）给体，碱 = 质子受体。
HCl + H₂O → Cl⁻ + H₃O⁺ 中，HCl 是酸、H₂O 是碱。
共轭酸碱对：强酸给出质子后得到弱共轭碱；弱碱得到质子后得到强共轭酸。
水既能给质子又能接受质子，所以在水溶液里扮演两性角色。

半反应法配平：把总反应拆成氧化半反应与还原半反应，分别配平（元素 → 氧用 H₂O → 氢用 H⁺ → 电荷用 e⁻），再让两边电子数相等后相加。

速率定律 · 初始速率法动画

反应速率是「单位时间内反应物转化为产物的量」（单位 mol·L⁻¹·s⁻¹）。速率定律把速率写成各反应物浓度的幂次乘积，而指数只能由实验测定，不能从方程式直接读出来。

[A] = 0.10 M基准
[A] = 0.20 M快 4×
[B] 减半慢 2×
[A] 加倍 → 速率 ×4 ⇒ 对 A 是 2 级；[B] 减半 → 速率 ×½ ⇒ 对 B 是 1 级
速率定律：Rate = k[A]ⁿ[B]ᵐ
• 反应级数：某一反应物的指数（如 n 是对 A 的级数）
• 总级数：所有指数之和 = n + m
• 速率常数 k：与温度有关，单位随总级数变化

初始速率法三步：① 找两组只改变一个反应物浓度的实验；② 比较速率之比 → 求出该反应物的级数；③ 把级数代回任一实验求 k。
例题（PPT）：A + 2B → C，测得 [A]=0.1/[B]=0.02 时 Rate=0.005；[A]=0.2/[B]=0.02 时 Rate=0.02；[A]=0.1/[B]=0.01 时 Rate=0.0025。
第 1→2 组：[A] 加倍、速率 ×4 → 对 A 是 2 级；第 1→3 组：[B] 减半、速率 ×½ → 对 B 是 1 级；
所以 Rate = k[A]²[B]，总级数 3，k = 0.005 / (0.1² × 0.02) = 25 L²·mol⁻²·s⁻¹。
影响速率的因素：反应物浓度、温度、接触面积（表面积）、催化剂，以及其他环境因素。

用哪种图是直线，就说明是几级

把浓度–时间数据做不同变换，哪一种变换后是直线，反应就是那一种级数。这是 AP 判断级数最快的方法。

[A]–t 直线 → 0 级
ln[A]–t 直线 → 1 级
1/[A]–t 直线 → 2 级
积分速率定律：
0 级：Rate = k　→　[A]ₜ − [A]₀ = −kt
1 级：Rate = k[A]　→　ln[A]ₜ − ln[A]₀ = −kt
2 级：Rate = k[A]²　→　1/[A]ₜ − 1/[A]₀ = kt

斜率的意义：0 级与 1 级图的斜率为 −k；2 级图的斜率为 +k。
一级反应的半衰期：t1/2 = 0.693 / k —— 一级反应的半衰期是常数，与初始浓度无关。

例题（PPT）：某一级反应 40 s 完成 25%。求 k 与达到 95% 所需时间。
剩余 75% → ln(0.75) = −kt → k = −ln(0.75)/40 = 7.19 × 10⁻³ s⁻¹；
达到 95% 完成（剩 5%）：ln(0.05) = −kt → t = −ln(0.05)/k ≈ 417 s。
再练一道（PPT）：1/[A]–t 图为直线且斜率 +3.40 × 10⁻² L·mol⁻¹·s⁻¹ → 二级反应，k = 3.40 × 10⁻²，速率定律 Rate = k[A]²。

麦克斯韦–玻尔兹曼分布

温度升高使分子能量分布曲线右移、变矮——超过活化能的分子比例大幅增加。

详细讲解　分子的能量并非都一样，而是呈分布（麦克斯韦–玻尔兹曼分布）。
  • 只有能量 ≥ 活化能 Ea 的分子碰撞才是有效碰撞。
  • 升温使分布曲线右移且变矮变宽——曲线右侧（超过 Ea 的部分）面积明显增大。
这就是「升温加快反应」的本质：有效碰撞比例大幅增加。注意曲线变矮但总面积（分子总数）不变，只是分布更「平坦」。

碰撞模型 · 只有能量够、方向对的碰撞才有效

绝大多数碰撞都不产生反应。一次有效碰撞必须同时满足两点：能量足够越过能垒，且取向正确。

粒子不断碰撞，但多数无效
阴影面积 = 能量 ≥ Eₐ 的比例（有效碰撞分数）
基元反应：一步完成、没有中间步骤的反应。它的速率定律可以直接由碰撞的粒子数写出（即分子数）。
三个（或更多）粒子同时碰撞的基元反应非常罕见 —— 所以基元反应多为单分子或双分子。

温度的影响：升温使麦克斯韦–玻尔兹曼分布整体右移、峰变低，Eₐ 右侧的面积（有效碰撞比例）大幅增加。
注意：「从方程式系数写速率定律」只对基元反应成立。总反应绝大多数是复合反应，必须靠实验测定级数。

反应能量图：从反应物 → 过渡态 → 产物

反应物与过渡态之间的能量差就是正反应的活化能 Eₐ
反应坐标：描述反应物重排为产物这一整套运动过程的横轴。
过渡态：能量最高点的不稳定组合（不是中间体 —— 中间体是能量低谷，能被检测到）。
ΔE / ΔH：反应物与产物之间的能量差。产物更低 → 放热；产物更高 → 吸热。

反应机理 · 中间体在几步之间「闪现」

反应机理是一系列按顺序发生的基元步骤。把各步相加应当得到总反应式。在这过程中先被生成、后被消耗的粒子叫中间体。

第 1 步（慢）A+B→C+D
第 2 步（快）C+E→D+F
C 在第 1 步生成、第 2 步被消耗 → 中间体，不会出现在总反应式中
中间体 vs 催化剂：
• 中间体：先生成、后消耗（净浓度从 0 开始，最后也为 0）
• 催化剂：先消耗、后再生（净浓度始终不变）

三步法求总反应：把各步相加，两边都出现的粒子互相约掉。剩余的就是总反应式。
例题（PPT）：Step 1: 2A + B → C + D；Step 2: C + E → D + F；Step 3: G → B + F。
C 在 step 1 生成、step 2 消耗 → 中间体；B 在 step 1 消耗、step 3 再生 → 催化剂；
相加并约去后总反应为 2A + E + G → 2D + 2F。

速率定律由最慢的一步决定

速率控制步（rate-determining step）：机理中最慢的那一步。若各基元步骤不可逆、或第一步就是慢步，则总速率定律 = 该慢步的速率定律。

「分子数」写法：基元步骤 A + B → … 的速率 = k[A][B]；2A → … 的速率 = k[A]²。指数就是该步中该粒子的系数。
例题（PPT）：C₄H₉Br → C₄H₉⁺ + Br⁻（慢）；C₄H₉⁺ + H₂O → C₄H₉OH₂⁺（快）；C₄H₉OH₂⁺ + H₂O → C₄H₉OH + H₃O⁺（快）。
总反应：C₄H₉Br + 2H₂O → C₄H₉OH + H₃O⁺ + Br⁻；中间体：C₄H₉⁺、C₄H₉OH₂⁺；
因为第一步是慢步，速率定律为 Rate = k[C₄H₉Br]（与 H₂O 浓度无关）。

稳态近似与多步能量图

如果第一步不是慢步，就不能直接把第一步写成速率定律，需要用近似方法处理。

稳态近似（steady-state）：假设活性中间体的浓度在反应过程中基本不变（生成速率 ≈ 消耗速率），据此把它消去，得到只含稳定物种的速率定律。

怎么判断用哪种：
• 第一步是慢步 → 直接取第一步的速率定律；
• 第一步很快、后面有慢步 → 用稳态近似处理中间体。
例题（PPT）：Step 1: A + B → E（快）；Step 2: E + B → C + D（慢）。
E 是中间体。对 E 做稳态近似可得 Rate = k[A][B]² —— 注意级数与「第一步的系数」并不一致，这正是不能用第一步直接写速率定律的原因。
多步反应的能量图有多个峰 —— 最高的那个峰对应最慢的步骤

催化 · 把能垒降下来

催化剂加快反应的方式只有两种：增加有效碰撞数，或提供活化能更低的路径。

两条路径的起点与终点相同（ΔH 不变），但能垒高度不同
催化剂的三条要点：
① 净浓度不变 —— 常在速率控制步被消耗，随后又在后续步骤再生；
② 剂不改变 ΔH、不改变平衡位置，只改变到达平衡的快慢；
③ 常见类型：结合型催化（催化剂与反应物结合，使其取向更有利，如酶）、酸碱催化（质子转移）、表面催化（反应物吸附在固体表面）。

吸热还是放热 · 两张能量图对比

温度变化说明系统发生了能量变化。反应发生时，系统的能量可能降低（放热）、升高（吸热）或不变。

放热：产物能量更低，向环境放热
吸热：产物能量更高，从环境吸热
放热反应：反应物（系统）失去的能量 = 环境得到的能量（以热或功的形式）。
吸热反应：系统从环境吸收能量（环境对系统传热或做功）。

溶解也可能是放热或吸热 —— 取决于溶解前后分子间/粒子间作用力的相对强弱。任何性质改变或变成另一种物质，都需要能量交换。
判断练习（PPT）：手摸冰变冷（吸热，手放热给冰）；冰变暖（吸热）；壶中水被加热沸腾（吸热）；水蒸气在冷管上凝结（放热）；冰激凌熔化（吸热）。

热传递与热平衡

T 高
热量 →
T 低
碰撞持续进行 → 温度相同（热平衡）
温度较高物体的粒子平均动能更大。两个物体接触时，粒子碰撞会把能量从高温物体传给低温物体，这个过程叫热传递。
一直碰撞下去，两个物体的平均动能趋于相同，也就是温度相同 —— 这时达到热平衡。

量热法测比热

高温金属投入冷水，热量由金属传给水，两者最终达到相同温度。

详细讲解　量热法通过测温度变化来求热量或比热。
  • 高温金属投入冷水，热量由金属传给水，直到两者温度相等（热平衡）。
  • 核心公式 q = mcΔT；由热量守恒：金属放出的热 = 水吸收的热。
据此可反求金属的比热容：c_金属 = m_水·c_水·ΔT_水 ÷ (m_金属·ΔT_金属)。升温的金属颜色可由红渐变为冷色，直观体现「降温放热」。

量热法 · q = mcΔT

量热实验测量热量的传递。核心公式只有一条：q = mcΔT，其中 c 是比热容。

低温：粒子动能小
加热后：粒子动能大
q = mcΔT：q 为热量（J），m 为质量（g），c 为比热容（J·g⁻¹·°C⁻¹），ΔT 为温度变化。
热力学第一定律：能量在化学与物理过程中守恒。
相同质量、不同比热容的物质，吸收同样的热量后温度变化不同 —— 比热容越大越「抗热」。

比热容与摩尔热容都常用于能量计算：加热系统使其能量增加，冷却则减少。系统改变能量的三条途径：加热/冷却、相变、化学反应。
例题 1（PPT）：银的比热容 = 0.24 J·g⁻¹·°C⁻¹（摩尔质量 107.9 g/mol）。
a. 150.0 g 银从 273 K 升到 298 K：q = 150.0 × 0.24 × 25 = 900 J；
b. 1.0 mol 银升高 1.0 °C：0.24 × 107.9 = 25.9 J·mol⁻¹·°C⁻¹（这就是摩尔热容）；
c. 用 1.25 kJ 把一块银从 12.0 °C 加热到 15.2 °C：m = 1250 ÷ (0.24 × 3.2) ≈ 1.63 × 10³ g。
例题 2（PPT · 热平衡）：100.0 g 的 90 °C 水加入 500.0 g 的 10 °C 水，求末温。
m₁cΔT₁ = m₂cΔT₂（c 相同可约掉）→ 100(90 − T) = 500(T − 10) → 9000 − 100T = 500T − 5000 → T = 23.3 °C。

相变中的分子排列

熔化/汽化时分子从有序排列变为无序，需要克服分子间作用力吸收能量。

详细讲解　同一物质的三态差别在于分子排列与运动方式。
  • 固态：分子固定在晶格上，只在原位振动，排列有序。
  • 液态：分子可相互滑动，较无序。
  • 气态：分子完全摆脱束缚、四散飞开。
熔化、汽化都要克服分子间作用力、吸收能量（ΔH > 0）。而熔化/汽化过程中温度不变（能量用于破坏作用力而非升温）。

相变能量 · 加热曲线上的两个「平台」

纯物质在相变过程中温度保持不变 —— 吸收的能量全部用来打破粒子间作用力，而不是升温。

上升段 = 升温；水平段 = 相变（温度不变）
熔化（固→液）与沸腾（液→气）都要吸收能量，系统的能量因此增加；
凝固（液→固）与凝结（气→液）都会放出能量，系统的能量因此减少。

可逆性：相变吸收的能量 = 反向相变放出的能量。例如某物质的摩尔凝结热 = −（摩尔汽化热）。

反应焓 ΔH

ΔH = q（恒压条件下），ΔH = H(产物) − H(反应物)
• ΔH < 0 → 放热（化学能转化为热）
• ΔH > 0 → 吸热（热转化为化学能）

产物与环境的能量交换：当产物温度与环境不同时，会通过热传递达到热平衡 —— 放热反应的产物把热能传给环境，吸热反应的产物则从环境吸收热能。
例题（PPT）：丙烷燃烧 C₃H₈(g) + 5O₂(g) → 3CO₂(g) + 4H₂O(l)，ΔH = −2221 kJ（每摩尔丙烷）。
5.00 g 丙烷（44.1 g/mol）= 5.00/44.1 = 0.1134 mol → ΔH = 0.1134 × (−2221) ≈ −252 kJ。

断键吸热 · 成键放热

反应中既有键的断裂、也有键的生成，两者都会改变系统的势能。比较两者的收支，就能判断放热还是吸热。

H—H→ HH
断键：吸收能量
HCl→ H—Cl
成键：放出能量
净结果 = 断键吸热 − 成键放热：放热更多 → 反应放热
估算方法：把反应物里所有键的平均键能相加 = 断键需要的能量；把产物里所有键的平均键能相加 = 成键放出的能量。
• 放出的 > 需要的 → ΔH < 0，放热
• 需要的 > 放出的 → ΔH > 0，吸热
例题（PPT）：用键能估算气相反应 ΔH ——
a. H₂ + Cl₂ → 2HCl：断键 H—H(436) + Cl—Cl(243) = 679 kJ；成键 2 × H—Cl(432) = 864 kJ → ΔH = 679 − 864 = −185 kJ（放热）。
b. N₂ + 3H₂ → 2NH₃：断键 N≡N(946) + 3×436 = 2254 kJ；成键 6 × N—H(391) = 2346 kJ → ΔH ≈ −92 kJ。

标准生成焓 ΔH°f

定义：在标准状态下，由组成元素生成 1 mol 化合物时的焓变。
• 元素的标准生成焓 = 0（如 O₂(g)、N₂(g)、C(s) 的 ΔH°f 都是 0）

反应焓计算式：
ΔH°reaction = Σn·ΔH°f(产物) − Σm·ΔH°f(反应物)
（n、m 是配平方程式中的系数，元素本身取 0）
例题（PPT）：4N₂H₃CH₃(l) + 5N₂O₄(l) → 12H₂O(g) + 9N₂(g) + 4CO₂(g)
已知 ΔH°f：N₂H₃CH₃ = +54、N₂O₄ = −20、H₂O(g) = −242、CO₂ = −393.5 kJ/mol；N₂ 元素为 0。
产物：12×(−242) + 9×0 + 4×(−393.5) = −2904 − 1574 = −4478
反应物：4×(+54) + 5×(−20) = 216 − 100 = 116
ΔH° = −4478 − 116 = −4594 kJ（强烈放热，适合做火箭推进剂）。

盖斯定律

不论走一步还是分几步，反应的总能量变化都一样——能量是状态函数。

详细讲解　盖斯定律：反应的总焓变只与始态、终态有关，与路径无关。
  • 无论一步完成还是分多步，总 ΔH 相同。
  • 因此可以用已知反应的 ΔH 相加减，算出难以直接测量的反应焓。
关键操作：把目标反应「拆」成已知反应，注意方向（逆反应 ΔH 反号）和系数（乘以几，ΔH 也乘以几）。本质是焓是状态函数。

盖斯定律 · 走哪条路，ΔH 都一样

总反应的焓变只取决于起点与终点，与中间经过几步无关。所以可以把已知反应「拼装」成目标反应。

蓝色直路与红色绕路：ΔH 完全相同
盖斯定律三条运算规则：
① 反应逆转 → ΔH 变号（数值不变）；
② 系数乘以 n → ΔH 也乘以 n；
③ 几个反应相加 → ΔH 也相加。

解题三步：① 依次考虑每个已知反应，判断是否需要逆转；② 判断需要乘多少倍；③ 把处理后的反应相加、约掉两边都有的物种，核对是否等于目标反应，最后把 ΔH 一起相加。
例题（PPT）：已知
① P₄(s) + 6Cl₂(g) → 4PCl₃(g)　ΔH = −1225.6 kJ
② P₄(s) + 5O₂(g) → P₄O₁₀(s)　ΔH = −2967.3 kJ
③ PCl₃(g) + Cl₂(g) → PCl₅(g)　ΔH = −84.2 kJ
④ PCl₃(g) + ½O₂(g) → Cl₃PO(g)　ΔH = −285.7 kJ
求 P₄O₁₀(s) + 6PCl₅(g) → 10Cl₃PO(g) 的 ΔH。
拼装：① + ②逆 + ③逆×6 + ④×10。
ΔH = −1225.6 + (+2967.3) + 6×(+84.2) + 10×(−285.7)
　　= −1225.6 + 2967.3 + 505.2 − 2857 = −610.1 kJ

平衡是动态的 · 正逆速率收敛动画

很多反应既能正向也能逆向进行。当正反应速率 = 逆反应速率时，宏观上不再变化，但微观上两个方向仍在同时进行 —— 这就是动态平衡。

两条速率曲线最终重合 —— 此时浓度不再变化
平衡的特征：
• 反应物与产物同时存在，浓度（或分压）保持恒定；
• 状态是动态的：正逆过程以相等速率持续进行，所以观察不到净变化；
• 平衡可以在任意方向建立 —— 从纯反应物出发、从纯产物出发，最终到达同一平衡状态。

常见的可逆过程：水的蒸发与凝结、气体的吸附与脱附、盐的溶解与沉淀；化学上还包括酸碱反应（质子转移）与氧化还原反应（电子转移）。
方向判据（7.2）：正速率 > 逆速率 → 净转化为产物；逆速率 > 正速率 → 净转化为反应物；两者相等时才达到平衡。

平衡建立动画

反应刚开始正反应快、逆反应慢；随着反应进行两者逐渐相等，浓度不再变化，达到平衡。

详细讲解　可逆反应中，正、逆反应同时进行。
  • 开始时只有反应物，正反应速率最大，产物不断生成。
  • 随产物增多，逆反应加快、正反应减慢，两条速率逐渐靠拢。
  • 当正逆反应速率相等时，各物质浓度不再变化——达到动态平衡。
关键：平衡是「动态」的，反应并未停止，只是正逆速率相等、宏观浓度不变。平衡常数 K 就是在这个状态下由各物质浓度算出的比值。

Q 与 K · 反应商向平衡常数的靠拢

反应商 Q 描述任意时刻各物种的相对浓度（或分压）；平衡常数 K 是 Q 在平衡时的取值。比较两者就能判断反应往哪个方向走。

Q K
Q 会不断向 K 靠拢，直到 Q = K 建立平衡
写法（以 jA + kB ⇌ lC + mD 为例）：
Kc = [C]l[D]m / ([A]j[B]k)　　（气相可用分压写成 Kp）

三条要点：
① 纯固体与纯液体不写入 —— 它们的浓度与物质的量无关；
② K 不带单位（只有动力学的 k 才带单位）；
③ 比较 Q 与 K：Q < K → 正向移动；Q > K → 逆向移动；Q = K → 已达平衡。
例题（PPT）：H₂O(g) + Cl₂O(g) ⇌ 2HOCl(g)，25 °C 时 K = 0.0900。判断下列条件是否平衡、不平衡则往哪移：
a. 三个分压都是 1.00 atm → Q = 1.00² / (1.00 × 1.00) = 1.00 > K → 逆向移动；
b. 200. / 49.8 / 21.0 torr → Q = 21.0² / (200. × 49.8) = 0.0443 < K → 正向移动；
c. 296 / 15.0 / 20.0 torr → Q = 20.0² / (296 × 15.0) = 0.0901 ≈ K → 已经平衡。

K 的大小与运算规则

逆转K → 1/K
系数 × cK → Kc
反应相加K → K₁ × K₂
Q 与 K 的数学形式相同，所以这些运算规则对 Q 同样成立
K 的大小说明什么：K ≫ 1 → 基本进行到底（产物占优）；K ≪ 1 → 几乎不发生（反应物占优）；K ≈ 1 → 两者量相当。
K 的测定：由平衡时的浓度或分压实测得到。
例题（PPT）：2H₂O(g) ⇌ 2H₂(g) + O₂(g)，K = 2.4 × 10⁻³。
① 4H₂O(g) ⇌ 4H₂(g) + 2O₂(g)（系数 ×2）→ K′ = (2.4 × 10⁻³)² = 5.8 × 10⁻⁶；
② 2H₂(g) + O₂(g) ⇌ 2H₂O(g)（逆转）→ K″ = 1 / (2.4 × 10⁻³) = 4.2 × 10²。

已知反应式 + 初始浓度 + K，就能预测平衡时的浓度。标准工具是 ICE 表：I（Initial 初始）、C（Change 变化）、E（Equilibrium 平衡）。

解题四步：① 写出配平方程式；② 列 ICE 表（注意系数决定变化量的比例）；③ 把 E 行代入 K 表达式；④ 解出 x 并算出各物种的平衡浓度。

什么时候可以近似：当 K 很小（或电离度很小）时，可以在 E 行把 x 视为可忽略以简化计算 —— 这属于常见近似手法，若题目要求精确解则需解二次方程。
例题 1（PPT）：N₂ + 3H₂ ⇌ 2NH₃，200 °C 密闭容器中初始 1.00 atm N₂ 与 2.00 atm H₂，平衡时总压 2.00 atm。求平衡时 H₂ 的分压与 Kp。
设 N₂ 消耗 x：总压 = (1.00 − x) + (2.00 − 3x) + 2x = 3.00 − 2x = 2.00 → x = 0.50 atm；
P(H₂) = 2.00 − 3(0.50) = 0.50 atm，P(N₂) = 0.50 atm，P(NH₃) = 1.00 atm；
Kp = 1.00² / (0.50 × 0.50³) = 16。
例题 2（PPT）：SO₂(g) + NO₂(g) ⇌ SO₃(g) + NO(g)，K = 3.75，四种气体初始浓度都是 0.800 M。
［SO₃］=［NO］= x，［SO₂］=［NO₂］= 0.800 − x → x²/(0.800−x)² = 3.75 → x/(0.800−x) = 1.94 → x = 0.528；
平衡浓度：［SO₂］=［NO₂］= 0.272 M，［SO₃］=［NO］= 0.528 M。

勒夏特列原理动画

对已达平衡的体系施加扰动（改变浓度/温度），观察平衡如何移动、重新建立。

详细讲解　勒夏特列原理：改变影响平衡的一个条件，平衡会向「减弱这种改变」的方向移动。
  • 增大反应物浓度 → 平衡正向移动（消耗多余反应物）。
  • 升温 → 平衡向吸热方向移动；降温 → 向放热方向移动。
  • 增大压强 → 平衡向气体分子数减少的方向移动。
注意：催化剂只加快达到平衡的速率，不改变平衡位置；平衡移动后会在新条件下建立新的平衡，K 仅在温度改变时才变。

勒夏特列原理 · 平衡总是「反抗」扰动

对平衡系统施加扰动，系统会朝减弱这个扰动的方向移动，建立新的平衡。

反应物
产物
加反应物 → 右移　｜　加产物 → 左移　｜　升体积 → 向气体分子数多的一侧移
平衡像一架天平：扰动让它倾一下，随即重新回到水平
四类常见扰动：
① 加入/移除某物种：加入谁就向消耗它的方向移；
② 改变体积/压强（气相）：体积减小 → 向气体摩尔数较小的一侧移；
③ 改变温度：升温向吸热方向移，降温向放热方向移；
④ 稀释：向溶质粒子数较多的一侧移。

不产生移动的情况：加入惰性气体（恒容）不改变各组分分压，平衡不移；加入催化剂只加快到达平衡的速度，不移动平衡。
例题（PPT）：3A(g) + 2B(aq) ⇌ 2C(g) + 2D(aq) + 2E(g)，ΔH = −66 kJ/mol（放热）。
[B] 增大 → 右移；[D] 增大 → 左移；[E] 减小 → 右移；[A] 减小 → 左移；
体积加倍 → 气体侧：左 3 mol、右 4 mol → 向右移；
加入热量（升温）→ 向吸热方向（左）移；放入冰浴（降温）→ 向右移；
加入 Ne（惰性）→ 不移；加入催化剂 → 不移。

用 Q 与 K 解释移动（7.10）

扰动使系统偏离平衡，本质上是让 Q ≠ K：
• 系统会通过让 Q 重新等于 K 来建立新平衡；
• 浓度/体积类扰动只改变 Q（K 不变）；
• 温度类扰动改变的是 K 本身。

两种情况下，各物种的浓度或分压都会重新分配，使 Q 与 K 再次相等。

两种酸碱定义 · pH 标尺动画

阿伦尼乌斯从「产生什么离子」定义酸碱，布朗斯特–劳里从质子转移定义 —— 后者更通用，也是 AP 的主用定义。

0714
pH < 7 酸性 ｜ pH = 7 中性（25 °C）｜ pH > 7 碱性 —— 标尺上的标记随 pH 往复移动
Arrhenius：酸在水中产生 H⁺，碱产生 OH⁻。
Brønsted–Lowry：酸 = 质子（H⁺）给体，碱 = 质子受体。
HCl + H₂O → Cl⁻ + H₃O⁺（HCl 是酸、H₂O 是碱）；NH₃ + H₂O ⇌ NH₄⁺ + OH⁻。

共轭关系：酸失去质子后剩下的部分叫共轭碱；碱得到质子后形成共轭酸。二者合称共轭酸碱对（如 HF / F⁻）。
pH 与 pOH：pH = −log[H₃O⁺]，[H₃O⁺] = 10−pH；pOH = −log[OH⁻]，[OH⁻] = 10−pOH
水的自偶电离：Kw = [H₃O⁺][OH⁻] = 1.0 × 10⁻¹⁴（25 °C）→ pKw = 14 = pH + pOH
• 纯水中 pH = pOH = 7.0（中性）；
• Kw 随温度变化，所以非 25 °C 时纯水的 pH 不再是 7.0。

强酸强碱（8.2）：HCl、HBr、HI、HClO₄、HNO₃ 完全电离，所以 [H₃O⁺] = 酸的初始浓度；1 族、2 族氢氧化物完全解离，[OH⁻] = 碱的初始浓度。
例题（PPT）：① 1.0 × 10⁻⁴ M H⁺ → pH = 4.00；② 0.040 M OH⁻ → pOH = 1.40 → pH = 12.60；
③ pH = 5.85 时 → [H⁺] = 10−5.85 ≈ 1.4 × 10⁻⁶ M，[OH⁻] = 1.0×10⁻¹⁴ ÷ 1.4×10⁻⁶ ≈ 7.1 × 10⁻⁹ M。

弱酸只「部分电离」

与强酸不同，弱酸分子只有很小一部分与水反应生成 H₃O⁺，绝大多数仍以分子形式存在。所以 [H₃O⁺] 远小于酸的初始浓度。

11 个分子里只有 2 个电离 → 电离度约 18%（示意图，实际弱酸通常远低于此）
弱酸平衡：HA(aq) + H₂O ⇌ H₃O⁺(aq) + A⁻(aq)　→　Ka = [H₃O⁺][A⁻] / [HA]，pKa = −log Ka
弱碱平衡：B(aq) + H₂O ⇌ HB⁺(aq) + OH⁻(aq)　→　Kb = [OH⁻][HB⁺] / [B]，pKb = −log Kb

由初始浓度和 pKa 求 pH：设电离量为 x → Ka = x²/(c − x)，小电离时可近似 x ≈ √(Ka·c)，再由 pH = −log x 得到结果。
电离度（percent ionization）：= (已电离的量 ÷ 初始量) × 100%。浓度越稀，电离度越大（但 [H₃O⁺] 更小）。
例题 1（PPT）：0.50 M HF（Ka = 7.2 × 10⁻⁴）求 pH。
x ≈ √(7.2×10⁻⁴ × 0.50) = √(3.6×10⁻⁴) ≈ 0.019 M → pH = −log(0.019) ≈ 1.72。
注意：溶液中主要物种是 HF 分子和 H₂O，H⁺ 与 F⁻ 只是少量产物 —— 所以由 HF 的电离（而不是水的自偶电离）控制 pH。
例题 2（PPT）：8.00 M 甲酸有 0.47% 电离，求 Ka。
[H₃O⁺] = 8.00 × 0.0047 = 0.038 M → Ka = 0.038² / (8.00 − 0.038) ≈ 1.8 × 10⁻⁴。
例题 3（PPT）：4.00 M 甲酸（Ka = 1.8 × 10⁻⁴）的电离度？
x ≈ 0.027 M → 电离度 = 0.027 ÷ 4.00 × 100% ≈ 0.67%。
对比例题 2：浓度从 8.00 M 降到 4.00 M，电离度反而从 0.47% 升到 0.67% —— 印证「越稀越电离」。

滴定全过程动画

碱液逐滴加入酸中，pH 缓慢上升；接近等当点时曲线陡升、指示剂突变。

详细讲解　酸碱滴定是用已知浓度的滴定剂去测定未知浓度。
  • 滴定过程中 pH 缓慢变化，接近等当点时发生突跃（pH 急剧变化）。
  • 等当点是酸与碱恰好按化学计量完全反应的时刻（弱酸强碱滴定的等当点呈碱性）。
  • 指示剂在突跃范围内变色，颜色突变即为滴定终点——应与等当点尽量接近。
要点：等当点由化学计量决定，终点由指示剂决定，二者越接近结果越准。

滴定曲线动态绘制

滴定过程中 pH 随滴定剂体积实时变化，等当点处出现陡峭的突跃。

详细讲解　滴定曲线把 pH 对加入的滴定剂体积作图。
  • 起始段平缓（弱酸的缓冲效应），pH 上升慢。
  • 半等当点处 pH = pKa（此时 [HA] = [A⁻]），是读取弱酸 pKa 的常用位置。
  • 等当点附近曲线几乎垂直（突跃），此后进入强碱过量区、pH 高而平缓。
要点：曲线形态由「被滴物是强酸还是弱酸」决定；弱酸曲线的等当点 pH > 7，且半等当点是关键读图点。

酸碱混合与滴定曲线

酸碱混合「按化学计量定量反应」。滴定曲线把 pH 对滴定剂体积作图，能一眼读出等当点与半等当点。

缓坡段（缓冲区）→ 陡升段（等当点附近）
四种混合情形（8.4）：
• 强酸 + 强碱：H⁺ + OH⁻ → H₂O，完全定量反应，pH 由过量的一方决定；
• 弱酸 + 强碱：HA + OH⁻ → A⁻ + H₂O。弱酸过量 → 形成缓冲液（用 H-H 方程）；强碱过量 → 由过量 OH⁻ 决定 pH；恰好等摩尔 → 由 A⁻ 的水解决定（偏碱性）；
• 弱碱 + 强酸：B + H₃O⁺ → HB⁺ + H₂O，情形与上面对称（等摩尔时偏酸性）；
• 弱酸 + 弱碱：HA + B ⇌ A⁻ + HB⁺，建立平衡。

滴定要点（8.5）：等当点时滴定剂的物质的量 = 待测物的物质的量（按系数比），可据此求待测浓度。
半等当点：[HA] = [A⁻]，此时 pH = pKa —— 这是从滴定曲线读取 pKa 的标准方法。
多元酸：滴定曲线上的多个陡升段对应多个可电离质子，每段半等当点给出一个 pKa。
例题（PPT）：0.20 mol HC₂H₃O₂（Ka = 1.8 × 10⁻⁵）与 0.030 mol NaOH 在 1.0 L 溶液中混合，求 pH。
OH⁻ 先与 HA 定量反应：HA 剩 0.20 − 0.030 = 0.17 mol，生成 A⁻ 0.030 mol → 形成缓冲液；
pKa = −log(1.8 × 10⁻⁵) = 4.74 → pH = 4.74 + log(0.030 / 0.17) ≈ 3.99。

分子结构如何决定酸性强弱

哪些质子会参与酸碱反应、以及它们有多「酸」，都能从分子结构推断。核心思想：共轭碱越稳定，酸性越强。

电负性把负电荷拉走 → 共轭碱更稳定 → 酸性更强
诱导效应吸电子基团通过 σ 键传递 → 稳定共轭碱
共振负电荷可离域到多个原子上 → 显著稳定
三种稳定化方式的示意图 —— 这也是「为什么 HClO₄ 是强酸」的答案
强酸：HCl、HBr、HI、HClO₄、HNO₃ —— 它们的共轭碱（Cl⁻、Br⁻、I⁻、ClO₄⁻、NO₃⁻）非常弱，靠电负性、诱导效应、共振（或其组合）稳定。
弱酸：羧酸（—COOH）是常见的一类。
强碱：1 族与 2 族氢氧化物 —— 共轭酸极弱。
常见弱碱：含氮碱（如氨）与羧酸根离子。
规律：电负性大的元素能相对稳定共轭碱，从而提高酸性（同一周期从左到右酸性增强；同一族从上到下酸性增强）。

pH 与 pKa · 谁占多数，一算就知道

pH < pKa：酸型 HA 占优pH > pKa：碱型 A⁻ 占优
把溶液的 pH 与酸的 pKa 比较，就能判断质子化状态
判据（8.7）：
• pH < pKa → 溶液更酸 → 酸型 HA 占多数；
• pH > pKa → 溶液更碱 → 碱型 A⁻ 占多数；
• pH = pKa → 两者浓度相等。

酸碱指示剂：HIn(aq) ⇌ H⁺(aq) + In⁻(aq)，质子化与去质子化状态颜色不同，因此颜色会随 pH 变化。指示剂用来标记滴定的终点；终点与等当点理想上尽量接近，但不必然相同。

缓冲溶液 · 加入酸/碱，pH 几乎不动

缓冲液同时含有共轭酸碱对的两个成员且浓度都较大。共轭酸中和外加的碱，共轭碱中和外加的酸 —— 所以 pH 被「稳住」。

加 H⁺→被 A⁻ 中和
加 OH⁻→被 HA 中和
pH 变化很小
缓冲体系里，外加的强酸/强碱都会被「吃掉」，所以 pH 变化远小于纯水
常见组成（8.8）：弱酸 + 它的盐（如 HF / NaF）、弱碱 + 它的盐（如 NH₃ / NH₄Cl）。

Henderson–Hasselbalch（8.9）：
pH = pKa + log( [A⁻] / [HA] )
它由弱酸电离的平衡表达式变形而来，说明缓冲液的 pH 取决于 pKa 与共轭酸碱的浓度比。
加入少量酸或碱时 [A⁻]/[HA] 的比例变化很小，所以 pH 几乎不变 —— 这就是缓冲作用的定量解释。
缓冲容量（8.10）：把缓冲组分的浓度同比例提高（比例不变）→ pH 不变，但缓冲容量（能中和的外加酸/碱的量）增大。
当共轭酸多于共轭碱时，对加碱的缓冲容量更大；反之当共轭碱更多时，对加酸的缓冲容量更大。
缓冲液最有效的区间是 pH ≈ pKa ± 1。

熵 · 物质与能量「越分散越无序」

熵（S）是分子无序程度（混乱度）的度量。自发过程的驱动力是宇宙总熵增加。

低熵：排列整齐、运动受限
ΔS > 0 →
高熵：分散开、自由运动
相变（固→液→气）、体积增大、温度升高，都会让熵增加
熵增加的三种典型情形（9.1）：
① 物质更分散：固 → 液 → 气（粒子更自由、占据更大体积）；
② 气体摩尔数增加：气相产物的总摩尔数 > 气相反应物的总摩尔数；
③ 能量更分散：升温使分子动理论中的动能分布变宽，熵随之增大。

恒温下气体体积增大 → 分子有更大活动空间 → ΔS 为正。
判断 ΔS 符号（PPT 例题）：酒精蒸发 → 正；水结冰 → 负；恒温压缩理想气体 → 负；恒压加热理想气体 → 正；NaCl 溶解 → 正（晶格被拆散、粒子分散）。

用绝对熵计算熵变（9.2）

公式：ΔS°反应 = Σn·S°(产物) − Σm·S°(反应物)
注意用的是绝对熵 S°（不是生成熵），单位 J·K⁻¹·mol⁻¹。
例题（PPT）：2Na(s) + 2H₂O(l) → 2NaOH(aq) + H₂(g)
已知 S°（J/K·mol）：Na(s) = 51、H₂O(l) = 70、NaOH(aq) = 50、H₂(g) = 131。
产物：2 × 50 + 131 = 231；反应物：2 × 51 + 2 × 70 = 242
ΔS° = 231 − 242 = −11 J·K⁻¹·mol⁻¹（略负 —— 因为水由液态变成水合离子，抵消了产生气体的熵增）。

熵增与自发性

孤立体系中粒子由有序趋于无序，熵增大——这是许多自发过程的驱动力。

详细讲解　熵 S 是混乱度（无序度）的度量。
  • 粒子由集中、有序趋向于分散、无序 → ΔS > 0，这是自发的方向。
  • 同一物质：气态熵 > 液态 > 固态；温度越高、粒子越多，熵越大。
判断自发：ΔG = ΔH − TΔS，ΔG < 0 时自发。很多「吸热却自发」的过程（如硝酸铵溶解）正是靠熵增驱动。

吉布斯自由能 · 判断「热力学是否有有利」

ΔG° 是判断过程热力学有利性的量度。AP 更推荐说「thermodynamically favored」而不是「spontaneous」（避免被误解为「突然、无缘无故」）。

ΔH°ΔS°ΔG° = ΔH° − TΔS°结论
−+永远 < 0任何温度都有利
+−永远 > 0任何温度都不利
−−低温 < 0低温有利
++高温 < 0高温有利
ΔH° 与 ΔS° 的符号组合决定「什么温度下有利」
标准态（9.3）：纯物质、1.0 mol/L 溶液、或 1.0 atm（1.0 bar）气体 —— 这些条件下的 ΔG 记作 ΔG°。
两种算法：
① 由生成自由能：ΔG°反应 = ΣnpG°(产物) − ΣnrG°(反应物)；
② 由焓与熵：ΔG° = ΔH° − TΔS°（T 用开尔文）。

快速判据：ΔS° > 0 且 ΔH° < 0 → 不必计算就知道 ΔG° < 0；ΔH° > 0 且 ΔS° < 0 → 不必计算就知道 ΔG° > 0。
为什么需要同时看焓和熵：水的凝固、硝酸钠的溶解就是典型 —— 单看焓或单看熵都不足以判断，必须放在一起算 ΔG°。

热力学控制 vs 动力学控制（9.4）

许多热力学有利的过程实际上几乎不发生，或发生得极慢 —— 这时过程处于动力学控制之下，最常见的原因是活化能很高。

重要区分：过程没有可观察的速率，并不等于系统处于平衡。如果已知某过程热力学有利却测不到速率，合理结论就是它受动力学控制。
（回想 Unit 5：热力学只说「能不能」，动力学才说「快不快」。金刚石转化为石墨就是经典例子 —— 有利，但慢到看不出来。）

ΔG° 与 K · 一边是热力学，一边是平衡

「热力学有利（ΔG° < 0）」等价于「平衡时产物占优（K > 1）」。两者由一条式子联系起来。

< 0ΔG°K > 1 产物占优
≈ 0ΔG°K ≈ 1 两者相当
> 0ΔG°K < 1 反应物占优
ΔG° 越负 → K 越大，定量关系是 ΔG° = −RT ln K
两个等价形式：
ΔG° = −RT ln K　　与　　K = e−ΔG°/RT，其中 R = 8.314 J·mol⁻¹·K⁻¹。

定性理解：ΔG° 接近 0 时 K 接近 1；ΔG° 与 RT 相比很大或很小时，K 会显著偏离 1。
ΔG° < 0 → 产物占优（K > 1）；ΔG° > 0 → 反应物占优（K < 1）。

耦合反应（9.6）· 用「有利」带动「不利」

不利反应ΔG° > 0
+
有利反应ΔG° < 0
→
总反应ΔG° < 0
两个反应共享中间体，把 ΔG° 相加 → 总过程变得有利
外部能源可以驱动不利过程：
① 电能驱动电解池或给电池充电；
② 光能驱动光合作用中 CO₂ → 葡萄糖的整体转化。

耦合反应：把「产生目标产物的不利反应」与一个有利反应耦合（如生物体内 ATP → ADP 的转化）。耦合系统中两个反应共享一个或多个共同中间体，相加后的总反应 ΔG° < 0，从而达成目标。
溶解的自由能（7.14 回顾）：ΔG°溶解 同时受三件事影响 —— 拆开固体内部的相互作用、溶剂围绕溶质重组、以及溶质与溶剂之间的相互作用。三者可能互相抵消，所以溶解的 ΔG° 正负需要具体分析。

原电池工作动画

电子从负极经导线流向正极，盐桥中离子定向迁移维持电中性，反应持续进行。

详细讲解　原电池把自发的氧化还原反应拆成两半，让电子通过外电路做功。
  • 负极（阳极）发生氧化：Zn → Zn²⁺ + 2e⁻，失去电子。
  • 正极（阴极）发生还原：Ag⁺ + e⁻ → Ag，得到电子。
  • 电子经导线由负极流向正极；盐桥中的离子定向迁移，维持两个半池的电中性。
要点：原电池对应 ΔG < 0（自发）；阳极是负极、阴极是正极，别与电解池混淆。

电化学电池 · 电子永远从阳极流向阴极

原电池（galvanic / voltaic）利用热力学有利的反应产生电压；电解池（electrolytic）则要靠外加电压驱动不利反应。

氧化发生在阳极、还原发生在阴极（电解池同样如此）
电池各组件的角色（9.7）：电极、半电池中的溶液、盐桥、电压/电流测量装置 —— 每个部件都有特定作用。
可以从宏观与粒子两个层面描述：电池类型、电子流动方向、各半电池发生的反应、电极质量变化、电极上是否析出气体、离子通过盐桥的流向。

类型对比：原电池涉及热力学有利的反应（E°>0）；电解池涉及热力学不利的反应（E°<0，需要外部电源）。
铁律：所有电化学电池都是「阳极氧化、阴极还原」。原电池中阳极是负极，电解池中阳极是正极。

电池电势 E° 与 ΔG°

电池电势（cell potential / emf）：把电子从还原剂「拉」向氧化剂的驱动力。单位是伏特 V = 每库仑电荷做 1 焦耳的功。
标准表给出的是还原电位（1 M、1 atm、25 °C）：
• 半反应逆转 → E° 变号；
• 半反应乘整数 → E° 不变（这点与 ΔH 不同！）；
• 原电池自发方向 = 使 E°cell 为正的方向。

计算公式：E°cell = E°(阴极) − E°(阳极)
例题（PPT）：Fe³⁺(aq) + Cu(s) → Cu²⁺(aq) + Fe²⁺(aq)
已知 Fe³⁺ + e⁻ → Fe²⁺ 的 E° = 0.77 V；Cu²⁺ + 2e⁻ → Cu 的 E° = 0.34 V。
要配平需逆转铜的半反应（Cu → Cu²⁺ + 2e⁻，E° = −0.34 V），并把铁的半反应 ×2（E° 仍为 0.77 V）：
总反应：Cu + 2Fe³⁺ → Cu²⁺ + 2Fe²⁺
E°cell = 0.77 − 0.34 = 0.43 V（为正，说明正向有利）。
与自由能的关系（9.8）：ΔG° 与电池电势的关系是
ΔG° = −nFE°，其中 n 为转移的电子摩尔数，F = 96,485 C/mol e⁻（法拉第常数）。
• E° > 0 → ΔG° < 0 → 热力学有利；
• E° < 0 → ΔG° > 0 → 不利，需要外加电压。
（F 可由一个电子的电荷 1.602 × 10⁻¹⁹ C 乘阿伏伽德罗常数 6.022 × 10²³ 得到。）
算一下上面的例子：n = 2、E° = 0.43 V → ΔG° = −2 × 96485 × 0.43 ≈ −8.3 × 10⁴ J/mol = −83 kJ/mol。

非标准条件下的电池电势（9.9）

真实系统的浓度往往不是标准态，此时电池电势会随浓度变化。电池电势是趋向平衡的驱动力 —— 离平衡越远，电势越大。

反应越接近平衡，|E| 越小；到达平衡（Q = K）时 E = 0
Nernst 方程：E = E° − (RT / nF) ln Q
• 标准电势 E° 对应 Q = 1 的条件；
• 系统接近平衡时 |E| 减小，平衡时（Q = K）降为 0；
• 偏离标准态后若使 Q 更远离平衡（比 Q = 1 更小）→ |E| 比 E° 更大；
• 若使 Q 更接近平衡 → |E| 比 E° 更小。

浓度电池：两个半电池只有浓度不同，自发电子流向就是「使浓度趋于相等」的方向。
重要提醒：电池不处于平衡，所以勒夏特列原理这类平衡论证不适用于电化学系统。AP 更看重对浓度效应的定性理解与推理，而不是套 Nernst 方程做繁琐计算。

电解与法拉第定律（9.10）

法拉第定律把「通了多少电」与「发生了多少化学变化」定量连起来，可以求电子数、电极上沉积/溶解的质量、电流、时间与离子电荷。

−+
电子从电源负极流向阴极 → 金属离子在阴极被还原并沉积
电流 × 时间 = 电荷量；电荷量 ÷ 法拉第常数 = 电子的物质的量
换算链条：
电荷量 q = I × t（C = A × s）→ 电子的物质的量 n(e⁻) = q / F → 按半反应系数比得到金属/气体的物质的量 → 换算成质量或体积。
公式：I = q / t，其中 F = 96,485 C/mol。
例题（PPT）：某未知金属 M 用电解沉积：2.00 A 电流通电 52.8 s，从 M(NO₃)₃ 溶液中析出 0.0719 g 金属。求 M 是什么。
q = I × t = 2.00 × 52.8 = 105.6 C；
n(e⁻) = 105.6 ÷ 96485 ≈ 1.09 × 10⁻³ mol；
由 M³⁺ + 3e⁻ → M，n(M) = 1.09 × 10⁻³ ÷ 3 ≈ 3.65 × 10⁻⁴ mol；
摩尔质量 = 0.0719 ÷ 3.65 × 10⁻⁴ ≈ 197 g/mol → 该金属是 金（Au）。
